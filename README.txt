DUBAI ISLAMIC BANK - HOMEPAGE REDESIGN (6 VERSIONS)

HOW TO VIEW
Open index.html in a browser and pick a version (v1 to v6).
Each version is a single file: vN/index.html (HTML, CSS and JavaScript in one file).
An internet connection is needed for fonts and photos.
Each version folder (v1 to v6) is self-contained: its own index.html plus an assets folder
with the official DIB logo (light and dark versions). Any folder can be shared on its own.

BEFORE GOING LIVE, REPLACE
- Photos: free Unsplash images loaded from Unsplash's servers. Replace with DIB's own photos,
  or download them and host them on DIB's server.
- Figures: profit rates, exchange rates, card fees and limits, calculator rates,
  branch list, offers and deals, and timeline dates are sample content.
  Confirm every figure with DIB.
- Forms: login, appointment and call-back forms are design prototypes and send nothing.
  They must be connected to DIB's real systems.

TESTED
All six versions checked at 375px (phone), 768px (tablet), 1024px and 1440px (desktop):
no sideways scrolling and no script errors.
